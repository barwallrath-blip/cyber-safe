What is Phishing?

Phishing is when attackers try to trick people into giving passwords or personal information by pretending to be trustworthy.

Strong Passwords

A strong password includes uppercase and lowercase letters, numbers, symbols, and should be at least 12 characters long.

Two-Factor Authentication

2FA adds an extra layer of protection by requiring a second verification step, like a code sent to your phone.

Security Tips

Never click suspicious links
Enable 2FA on all accounts
Use a password manager
Keep software updated
